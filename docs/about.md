ImageLab is a standalone tool which supports anyone to get started with image processing related concepts and techniques in an interactive, visual way. Users drag and connect blocks to build image processing pipelines without writing code. ImageLab is ideal for beginners learning image processing and for experienced users who want a quick test environment.

The project now features both a legacy Electron desktop application and a modern web-based solution with React frontend and Python FastAPI backend.

[![License](https://img.shields.io/badge/License-Apache%202.0-blue.svg)](https://opensource.org/licenses/Apache-2.0)

## Supported Image Processing Operations

### Basic Operations
- Read Image / Write Image

### Conversions
- Color Maps / Color to Binary / Gray Image / Gray to Binary

### Blurring
- Simple Blur / Gaussian Blur / Median Blur

### Drawing
- Draw Arrow Line / Draw Circle / Draw Ellipse / Draw Line / Draw Rectangle

### Geometric Transformations
- Rotation / Scaling / Perspective transforms

### Filtering & Enhancement
- Edge Detection / Smoothing / Enhancement filters / Sobel Derivatives

### Thresholding
- Multiple thresholding techniques and binary operations
